# uber-analysis-using-sql


## Overview
This project analyzes Uber ride booking data using **MySQL** to generate business insights on customer behavior, revenue trends, ride cancellations, payment preferences, and vehicle performance. The project demonstrates advanced SQL techniques commonly used in real-world data analytics.

## Objectives
- Analyze booking and revenue trends
- Identify high-value customers
- Evaluate cancellation patterns
- Compare vehicle performance
- Perform customer segmentation
- Generate business-driven insights


## SQL Concepts Used
- Data Cleaning
- Joins
- CTEs (Common Table Expressions)
- Subqueries
- Aggregate Functions
- Window Functions (`ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `NTILE()`, `LAG()`, `LEAD()`)
- Running Totals
- Time-Series Analysis
- Conditional Aggregation

## Key Business Analyses
- Revenue & Month-over-Month Growth
- Customer Segmentation (Pareto Analysis)
- Rolling Revenue Analysis
- Ride Cancellation Analysis
- Vehicle & Payment Method Performance
- Route & Location Analysis
- Customer Ride Frequency & Consecutive Ride Streaks
